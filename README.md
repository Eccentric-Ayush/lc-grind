## 🚀 How to Run

### C++
You can compile and run the C++ solutions using `g++` or any standard C++ compiler:
```bash
g++ -std=c++17 problem_name.cpp -o solution
./solution
```

### Python
For Python solutions, simply run them using your standard Python 3 interpreter:
```bash
python problem_name.py
```
